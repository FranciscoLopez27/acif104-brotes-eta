Arquitectura del sistema

Diseño del frontend y del backend del prototipo. El backend reutiliza los módulos de src/ del repositorio.

Frontend

Streamlit (Python)
  • Formulario validado
  • Resultado con dos probabilidades y nivel
  • Factores SHAP
  • Panel histórico
  • Registro del resultado real

Backend

Módulo de Python
  • Validación de datos (datos.py)
  • Codificación y tasa histórica regional
  • Predicción y umbral (evaluacion.py)
  • Explicación SHAP

Modelo

Random Forest v1.0
  • Pipeline versionado (codificador + modelo)
  • Umbral 0,397 (recall ≥ 0,70)
  • Reentrenamiento anual con datos del DEIS

Datos y monitoreo

SQLite (prototipo)
  • Registro de predicciones con fecha y versión
  • Resultados reales
  • Métricas por año y región
  • Alertas bajo la meta

Flujo de una consulta

  1. El profesional de la SEREMI ingresa el brote en el formulario (frontend).
  2. El backend valida los datos: campos obligatorios, coherencia de fechas y listas cerradas.
  3. Se construyen las variables (retraso, temporada, tasa histórica regional) con el mismo código del entrenamiento.
  4. El modelo estima la probabilidad con la capacidad real de la región y con el nivel de referencia.
  5. SHAP calcula los factores que más influyeron y el frontend muestra el resultado y su nivel.
  6. La predicción se registra; al cerrar la investigación se registra el resultado real y se actualizan las métricas de monitoreo.

Usabilidad (RNF01)

Interfaz en español, lenguaje no técnico, listas cerradas, validación inmediata y diseño adaptable a pantallas pequeñas.

Escalabilidad (RNF03)

El modelo está separado de la interfaz: se reemplaza un archivo versionado sin modificar el frontend. La predicción de un brote toma milisegundos; puede migrarse a una API (FastAPI) y a PostgreSQL.

Explicabilidad (RNF02)

Cada predicción muestra sus factores principales (SHAP) y la diferencia entre ambos escenarios regionales.

Seguridad (RNF04)

No se registran datos personales ni identificación de establecimientos; conexión cifrada (HTTPS) del servicio de publicación.
